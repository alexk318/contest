По условию задачи мы точно знаем что чисел, не равных искомому числу ровно по три штуки.

2. [Count Commas in Range II](https://leetcode.com/problems/count-commas-in-range-ii/description/) (Medium)

Число запятых для заданного числа хранится в переменной s.
Число запятых можно найти с помощью логарифма из числа по основанию 1000. Такой способ дает осечку, если логарифм числа
имеет много девяток после запятой. В таком случае программа доокругляет число до целого и floor не срабатывает. Если произошла осечка, то
берется число которое больше заданного и первое присвоение к result будет присвоение отрицательного числа. Этим можно воспользоваться и просто
отнимать единицу от s в таком случае.

Между двумя числами находится (Больше число - Меньшее число + 1) чисел. Домножаем его на кол-во запятых.

Сначала находится число запятых между искомым число и наименьшим число с таким же количество запятых.
Число запятых для оставшегося интервала ищется в цикле for.

Идея заключается в том, чтобы разделить слова и шаблон на несколько частей, начинающихся с заглавной буквы. Все это будем хранить в векторе.
Для этого заведем функцию split_string_by_uppercase(std::string query). Т. к. в тест-кейсах имеются случаи когда слова начинаются с маленьких букв,
в этой функции сначала ищется индекс первой заглавной буквы first_capital_index.

Далее смотрим, имеется ли в i-ой части слова все буквы из i-ой частьи шаблона. Если шаблон верный, то этих частей должно быть поровну.
После обнаружения того, что слово не соответствует шаблону, цикл перебирающий части шаблона будет зря отрабатывать. Чтобы этого избежать используется is_correct

4. [Shift 2D Grid](https://leetcode.com/problems/shift-2d-grid/description/) (Easy)

Для удобства введем функцию shift_right(std::vector<int>& vec), осуществляющую перестановку всех элементо вправо.
Последний элемент становится первым.

Матрица реализуется вектором строк, что удобно для перемещения первых двух столбцов влево (Просто применив (shift_right)),
но неудобно для изменения порядка элемнтов в последнем столбце. Поэтому создается отдельный вектор, где элементы столбца расположеные горизонтально.
